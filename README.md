# Kotlin Financial Calculator 📊

A simple console application written in Kotlin to calculate total earnings, track expenses, and compute net income. 
This project was completed as part of the **Hyperskill** (JetBrains Academy) learning platform.

## Features
* Displays itemized earnings from a predefined product map.
* Automatically calculates total income using collection summing.
* Interactive input for staff and other business expenses.
* Computes and prints the final net income.

## How to Run
1. Make sure you have [Kotlin compiler](https://kotlinlang.org/) or an IDE installed (like IntelliJ IDEA or Android Studio).
2. Clone the repository or copy the code.
3. Run the `main` function.
